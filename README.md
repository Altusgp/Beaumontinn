# Beaumont Inn Landing Page

A static website for the historic Beaumont Inn in Harrodsburg, Kentucky.

## Features
- Responsive design
- Beautiful gallery of rooms
- Information about the inn and amenities
- Historic charm and elegance

## Deployment
This website is deployed on GitHub Pages. Visit: [https://biopathogenix.github.io/Beaumontinn/](https://biopathogenix.github.io/Beaumontinn/)

## Pages
- **index.html** - Main landing page
- **preview.html** - Room preview page

## Local Development
Simply open `index.html` or `preview.html` in your browser to view the website.
